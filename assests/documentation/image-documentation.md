# Bildauswahl und Akteninhalte

Nur Bilder eintragen, die tatsächlich im Praxisprojekt verwendet werden. Die Bildauswahl wird über die drei Kriterien auf dem zweiten Tabellenblatt begründet. Die Aktennummer wird im Interface automatisch generiert und daher nicht in dieser Tabelle geführt. Für jede Kategorie stehen genau drei festgelegte Sammlungen zur Verfügung. Die Kontextbeschreibung ist für die ausführliche Akte gedacht und umfasst höchstens zwei Sätze; der Projektionskurztext ist auf einen sehr kurzen Satz reduziert. Die kurze institutionelle Relevanz wird im Interface angezeigt; die ausführliche Begründung bleibt in dieser Dokumentation erhalten.
